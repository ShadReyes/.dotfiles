# brando (personal plugin)

Vendored skills from [`brs98/.dotfiles`](https://github.com/brs98/.dotfiles),
namespaced under `brando:`.

This is a local skills-dir plugin. It lives under `~/.dotfiles/skills/brando/`
and is symlinked into `~/.agents/skills/brando` by `sync-skills.sh`.
