# Personalized designs

Inspect the installed DecalFlow package/renderer contract before promising editable fields. Use exact local fonts and supported bindings; an outlined sample name is fixed geometry, not a template. Preserve fixed artwork separately from variable fields. If requested lettering or characters exceed renderer support, retain the original and identify the specific limitation for review.

Define customer-visible field labels, required/optional status, allowed characters and formats, input lengths, and how each answer maps into DecalFlow fields. Include the sample shown in listing photos. A character limit alone does not establish geometric fit: glyph widths, word breaks, diacritics, and combinations of fields matter.

Before design approval, inspect authoring previews for representative short, long/wide, narrow, and permitted special-character inputs and dry-run package import without registration. Label these as authoring/package checks, not production-renderer proof. After approved registration, validate the same inputs through actual DecalFlow preparations. Prepare each with the actual template and inspect bounds, shape, overflow, Piece grouping, and `job size-limits`. Record which examples informed physical testing and the approved input domain. Use the most restrictive tested fit result for advertised sizes, while treating sample coverage as evidence rather than proof of every possible string.

For qualification, identify inputs that stress fine details at the minimum and Piece dimensions/application at the maximum. Include additional endpoint specimens when one input cannot represent both risks. The user approves physical results for the recorded scope.

Overflow requires review. Do not automatically shrink text, substitute fonts, drop characters, or change spacing to force a fit. A change to the approved template follows the design/version approval loop.

## Etsy and order intake

Inspect the Etsy MCP's live personalization contract; use its supported question fields rather than guessing a legacy boolean or assuming the template listing already has them. The default fixed-design listing has no personalization, so create the required questions explicitly for a personalized product. Map answers to the exact DecalFlow field IDs; if the current intake cannot represent them, report the mapping blocker rather than claiming completion.

Read back instructions, labels, requiredness, length/format limits that Etsy supports, and answer ordering/IDs. Constraints Etsy cannot enforce must appear clearly in instructions and be checked during order preparation. Do not advertise arbitrary personalization when the renderer supports a narrower domain.

A launch qualification does not approve every future order. Recompute exact personalized geometry, fit, and overflow for each order. Unexpected inputs or unqualified details require review before production. Automatic uncuttable-section detection remains future work.
