# vercel (personal plugin)

Official skills vendored from Vercel repositories and namespaced under
`vercel:`.

This is a local skills-dir plugin. It lives under
`~/.dotfiles/skills/vercel/` and is symlinked into
`~/.agents/skills/vercel` by `sync-skills.sh`.

## Skills

- `vercel:ai-sdk`
- `vercel:vercel-cli`

## Upstream

The `ai-sdk` skill was vendored from
`skills/use-ai-sdk` at commit
`3c98985d44482f36704acd1a76f351f329028b5f`.

The `vercel-cli` skill was vendored from
[`vercel/vercel`](https://github.com/vercel/vercel), path
`skills/vercel-cli`, at commit
`17d9ebaf8e9b335d550dea1a243743a74edc772e`.
