# matt (personal plugin)

Vendored skills from [`mattpocock/skills`](https://github.com/mattpocock/skills),
namespaced under `matt:`.

This is a local skills-dir plugin. It lives under `~/.dotfiles/skills/matt/`
and is symlinked into `~/.agents/skills/matt` by `sync-skills.sh`.

## Skills

- `matt:writing-great-skills`
- `matt:grill-me`
- `matt:teach`
- `matt:tdd`
- `matt:to-prd`
- `matt:grill-with-docs`
